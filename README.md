# Aphros Void

Deterministisches 2D-Weltraumspiel: X4-artiges Konzernmanagement trifft persönlich steuerbare Miner, Frachter und Jäger im gemeinsamen Wirtschafts- und Flugkern. Statisches HTML/CSS/Vanilla JavaScript für iPad Safari, GitHub Pages und NAS.
